# Provncloud SDK (rust-wasm)

WebAssembly bindings for the Rust reference implementation used by the TypeScript SDK.

This crate is primarily an internal monorepo package. It exposes JSON/string-based WASM bindings for:

- key generation
- claim creation
- claim signing
- claim verification
- SHA-256 hashing

Source of truth and protocol details:

- [Monorepo](https://github.com/provnai/provn-sdk)
- [Protocol Spec](https://github.com/provnai/provn-sdk/blob/main/spec/SPEC.md)
